# Sales SQL Analytics Dashboard

An interactive SQL-powered sales analytics dashboard built using Python, SQLite, and Streamlit for business intelligence insights.

## Features

- SQLite database integration
- Revenue analysis by city
- Branch performance comparison
- Product line revenue insights
- Payment method analysis
- Customer rating trends
- Interactive visual dashboard

## Tech Stack

- Python
- SQLite
- Pandas
- Streamlit
- Matplotlib

## SQL Concepts Used

- SELECT
- GROUP BY
- ORDER BY
- SUM()
- AVG()
- COUNT()
- Aggregate analysis

## Key Business Questions Answered

- Which city generates highest revenue?
- Which product line performs best?
- Which branch performs strongest?
- What payment method is most popular?
- Which branch has highest customer satisfaction?

## Dashboard Metrics

- Total Revenue
- Average Customer Rating
- Revenue by City
- Revenue by Branch
- Product Line Performance

## Run Locally

```bash
pip install -r requirements.txt
streamlit run app.py
```

## Business Value

Transforms raw transactional sales data into actionable business insights for decision-making.
